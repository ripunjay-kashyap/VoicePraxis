# VoicePraxis Contracts: Episode JSON v0.2

This directory defines the data contract between the backend pipeline (FastAPI + Modal + Gemini) and the frontend application (Next.js).

- `model_output.schema.json`: JSON Schema for raw output generated by Gemini from video + audio.
- `episode.v0.2.example.json`: Complete example of an assembled episode for the container reheating task.

---

## Episode v0.2 Field Reference

Each line describes what the field means, who writes it, and when it is null.

### Root Level
- `schema_version`: Contract specification version string (`"0.2"`); written by backend assembler; never null.
- `episode_id`: Unique string identifier for the episode; written by backend at ingest; never null.
- `media_ref`: Path or storage key for the playable MP4; written by backend media pipeline; never null.
- `duration_seconds`: Total video duration in decimal seconds; written by backend media pipeline; never null.
- `status`: Object holding processing lifecycle state (`stage` and `error`); written by backend job runner; never null.
- `pipeline`: Object logging inference provenance (`model`, `fps`, `res`, `mode`, `prompt_version`, `audio`); written by backend assembler; never null.
- `scene`: Short description of the physical location or environment; written by Gemini model; never null.
- `task`: Object describing the high-level task goal, intent, and outcome; written by Gemini model; never null.
- `narration`: Array of all verbatim spoken utterances in chronological order; written by Gemini model / audio pipeline; empty array `[]` if no speech detected.
- `actions`: Array of chronological physical action steps extracted from video; written by Gemini model + backend assembler; never null.
- `pending_questions`: Array of active questions for human clarification (steps where `why_matters` is true and `stated_reason` is null); written by backend assembler; empty array `[]` if none.
- `clarifications`: Array of answered operator clarifications; written by backend when answered; empty array `[]` initially.
- `template_check`: Comparison object against a reference task template; written by template comparison feature; null when open mode is used or `TEMPLATES` flag is off.
- `video_only`: Parallel model output without audio for side-by-side evaluation; written by side-by-side feature; null when `SIDE_BY_SIDE` flag is off.
- `human_corrections`: Array of human edits preserving original model output; written by review API; empty array `[]` initially.

### `status`
- `status.stage`: Current processing stage (`"uploaded"` | `"converting"` | `"analysing"` | `"linking"` | `"ready"` | `"failed"`); written by backend job runner; never null.
- `status.error`: Human-readable error description; written by backend job runner; null unless stage is `"failed"`.

### `pipeline`
- `pipeline.model`: Gemini model identifier string (e.g. `"gemini-3.8-flash"`); written by backend pipeline; never null.
- `pipeline.fps`: Video frame rate sampled for analysis; written by backend pipeline; never null.
- `pipeline.res`: Video resolution mode (`"default"` | `"low"`); written by backend pipeline; never null.
- `pipeline.mode`: Processing strategy (`"static"` | `"agentic"`); written by backend pipeline; never null.
- `pipeline.prompt_version`: Prompt template identifier (e.g. `"v1"`); written by backend pipeline; never null.
- `pipeline.audio`: Boolean indicating whether audio was provided to the model; written by backend pipeline; never null.

### `task`
- `task.name`: Short imperative or gerund title of the overall activity; written by Gemini model; never null.
- `task.declared_intent`: Object (`{ text, utterance_id }`) with what the actor verbally stated they want to achieve; written by Gemini model; null if the actor never verbally stated an intent.
- `task.declared_intent.text`: Spoken goal sentence verbatim; written by Gemini model; null when declared_intent is null.
- `task.declared_intent.utterance_id`: ID of the corresponding utterance in `narration`; written by Gemini model; null when declared_intent is null.
- `task.outcome`: Final outcome of the overall task (`"success"` | `"failed"` | `"unresolved"`); written by Gemini model; never null.
- `task.outcome_evidence`: Visual/audio observations supporting the task outcome; written by Gemini model; never null.

### `narration[]`
- `narration[].id`: Unique identifier for the utterance (e.g. `"u1"`); written by Gemini model / pipeline; never null.
- `narration[].start`: Start time in decimal seconds from clip start; written by Gemini model / audio pipeline; never null.
- `narration[].end`: End time in decimal seconds from clip start; written by Gemini model / audio pipeline; never null.
- `narration[].text`: Verbatim transcript of what was spoken; written by Gemini model / audio pipeline; never null.
- `narration[].mode`: Temporal relation to the action described (`"before"` | `"during"` | `"after"` | `"general"`); written by Gemini model; never null.

### `actions[]`
- `actions[].id`: Unique identifier for the action step (e.g. `"action-01"`); written by backend assembler; never null.
- `actions[].start`: Start time in decimal seconds from clip start; written by Gemini model; never null.
- `actions[].end`: End time in decimal seconds from clip start; written by Gemini model; never null.
- `actions[].observed_action`: Objective description of physical movement visible in video; written by Gemini model; never null.
- `actions[].instruction`: Imperative robot-trainable instruction command; written by Gemini model; never null.
- `actions[].visual_evidence`: Visual observations confirming this step; written by Gemini model; never null.
- `actions[].stated_reason`: Spoken reason given by the actor (`{ text, utterance_id, source }`); written by Gemini model; null if no spoken reason was given for this step.
- `actions[].inferred_reason`: Model's own reasoned guess based strictly on visible context; written by Gemini model; null if reason cannot be determined from video.
- `actions[].why_matters`: Boolean flag indicating if this step is a critical decision/recovery point where knowing why is needed; written by Gemini model; never null.
- `actions[].attempt`: Execution classification (`"first"` | `"retry"` | `"recovery"`); written by Gemini model; never null.
- `actions[].outcome`: Step result (`"success"` | `"failed"` | `"unresolved"`); written by Gemini model; never null.
- `actions[].uncertainty`: Array of reviewer check reasons; written by Gemini model; empty array `[]` if confident.
- `actions[].review_status`: Step review status (`"accepted"` | `"flagged"` | `"rejected"`); written by backend assembler; never null.
- `actions[].human_corrections`: Array of human overrides applied to this step; written by review API; empty array `[]` initially.

### `pending_questions[]`
- `pending_questions[].id`: Unique question identifier (e.g. `"pq-01"`); written by backend assembler; never null.
- `pending_questions[].action_ref`: ID of the target action step; written by backend assembler; never null.
- `pending_questions[].kind`: Classification of question (`"no_reason"` | `"unclear"` | `"failure"`); written by backend assembler; never null.
- `pending_questions[].question`: Natural language question asked to operator; written by backend assembler; never null.
- `pending_questions[].source`: Component that triggered the question (`"mvp_check"` | `"copilot"`); written by backend assembler; never null.

### `clarifications[]`
- `clarifications[].action_ref`: ID of the target action step; written by backend when answered; never null.
- `clarifications[].question`: Clarification question asked; written by backend when answered; never null.
- `clarifications[].answer`: Answer provided by operator; written by frontend / backend; never null.
- `clarifications[].asked_at`: ISO 8601 timestamp of question answer; written by backend; never null.
